# Phase 1 — MVP Foundation

## Exit criteria from the master plan

- [x] Repository structure, CI, environment template
- [x] Database schema + migration
- [x] Admin/editorial workflow minimal
- [x] Home / Explore
- [x] Entity pages
- [x] Marga directory/profile
- [x] Source Library
- [x] Search MVP
- [x] Related content
- [x] Responsive + accessibility baseline
- [x] Pilot seed content

## Scope guard

Phase 1 proves the foundation. It does not try to encode every Batak rule.

Features explicitly deferred:
AI, public accounts, community contribution, personal genealogy, tarombo visualization,
partuturan calculator, cultural map, rich media galleries, and full multilingual UI.

## Definition of Done

A contributor can clone the repo, install dependencies, run the public site without credentials,
connect a Supabase project via environment variables, apply the migration/seed, sign into the
editorial area after receiving a role, create draft entities, search published knowledge, and run
the project quality commands.
