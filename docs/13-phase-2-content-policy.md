# Phase 2 Interactive Content Policy

## Cultural Map

- Prefer administrative places or representative reference points.
- Do not draw a cultural boundary unless a qualified source explicitly supports that boundary and the UI states the source/method.
- A point must state its precision and limitation.

## Adat Timeline

- A timeline is not automatically a ritual instruction.
- Each substantive practice step should have source provenance.
- Regional/family/community differences are stored as variations.
- Sensitive ritual detail can remain unpublished even if technically available.

## Dictionary

- Do not bulk-copy copyrighted dictionaries.
- Publish selected entries only when a source and locator can be recorded.
- Keep language variety separate from ethnic/cultural identity.

## Media

- Online availability is not permission to reproduce.
- Unknown rights => metadata only.
- Store rights holder, license, attribution, and usage note before copying media into project storage.
