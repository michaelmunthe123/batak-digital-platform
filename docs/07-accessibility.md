# Accessibility Baseline

Phase 1 target: practical WCAG-oriented baseline, not a certification claim.

Implemented:
- semantic `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- one primary heading per page
- explicit form labels
- skip-to-content link
- visible keyboard focus styles
- no information conveyed by color alone
- responsive layouts
- meaningful link text
- loading status has screen-reader text
- static content remains usable without client JavaScript where practical

Before public launch:
- keyboard-only walkthrough
- 200% zoom check
- mobile viewport checks
- automated accessibility audit
- contrast review on actual final palette
