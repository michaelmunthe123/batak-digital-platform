# Phase 2 — Content Expansion & Interactive Culture

Phase 2 implements exactly the six roadmap deliverables defined in the master project plan:

1. Cultural Map
2. Adat Timeline
3. Dictionary / Language Foundation
4. Media Galleries with Rights Metadata
5. Improved Search / Filter
6. Content Completeness Dashboard

## Still out of scope

- Tarombo visualizer
- Relationship explorer / kinship graph UI
- Partuturan calculator
- Contributor/public accounts
- Community proposal workflow
- AI assistant / semantic search

## Product rule

Interactive features must never create stronger cultural certainty than the underlying sources support.
