# Genealogy Privacy & Inference Policy

## Fail closed

When data is insufficient, the correct result is **unknown**. The application must never fill a missing genealogical link from surname similarity, clan popularity, geographic proximity, or an LLM guess.

## Living people

Phase 3 is not a public genealogy social network. Living people are never public in the database model. Editors should minimize personally identifying data and prefer labels suitable for the research purpose.

## Partuturan

The calculator accepts an **explicit known relationship/role** and maps it to a sourced rule. It is not a tool where two marga names are entered and a kinship relation is magically generated.

## Martutur / ertutur

Published source material itself describes kinship positioning as contextual interaction involving marga and family relationships. The product therefore treats calculator outputs as documented guidance, not a replacement for family/community context.

## Demo graph

The public seed tarombo is fictional. Its purpose is to test visualizer behavior, privacy, and graph algorithms without publishing unverified lineage.
