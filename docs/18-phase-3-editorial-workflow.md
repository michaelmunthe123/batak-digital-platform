# Phase 3 Editorial Workflow

## Real genealogy dataset

1. Register source(s) first.
2. Create genealogy dataset as `restricted` or `private` draft.
3. Add nodes with conservative privacy settings.
4. Add genealogy edges. Real edges require a source in the admin action.
5. Submit dataset for review.
6. Reviewer checks evidence, node privacy, conflicts, and context.
7. Only material safe for publication may move to public/published.

## Kinship rule

1. Choose cultural context.
2. Describe the relationship in plain Indonesian.
3. Add term and explanation.
4. Link a source and locator.
5. Reviewer classifies claim status and publication status.

## Disputes

Do not delete a credible conflicting tradition. Store separate evidence, context, and claim status. UI must explain the difference.
